# 📊 Dashboard de Análise de Dados com Python
Projeto desenvolvido durante uma imersão de dados, com foco em análise exploratória e visualização interativa utilizando Python.

## 🚀 Sobre o projeto
Este projeto tem como objetivo analisar um conjunto de dados e extrair insights relevantes por meio de visualizações interativas.
A aplicação foi desenvolvida utilizando Streamlit, permitindo uma navegação dinâmica e intuitiva.

## 🛠️ Tecnologias utilizadas
- Python  
- Pandas  
- Plotly  
- Streamlit

## 📊 Análises realizadas
- Limpeza dos dados
- Exploração dos dados  
- Comparação entre categorias  
- Visualização de padrões

## 🧠 Principais insights
- Os dados mostram diferenças claras entre os grupos analisados  
- Algumas categorias se destacam com valores mais altos  
- Existe um padrão consistente ao longo dos dados
